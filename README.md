\# DevOps CI Project



\## Project Name

DevOps\_CI\_24BCS284



\## Description

A simple Java application created to demonstrate version control using Git and GitHub and continuous integration using Jenkins.



\## Technologies Used

\- Java

\- JUnit 5

\- Maven

\- Git

\- GitHub

\- Jenkins



\## Project Structure

\- src - Application source code

\- tests - JUnit test cases

\- pom.xml - Maven configuration



\## How to Run



Compile and run the application using Java:



&#x20;   javac src\\main\\java\\App.java

&#x20;   java -cp src\\main\\java App



Run the tests using Maven:



&#x20;   mvn test
